# W12 — BioWatch International site

Paths relative to `apps/biowatch` unless marked `apps/web`; code at `c73bb8d`. This app is the parent organisation's one-page static site (`/` only, English, zero client JS, `revalidate = 3600`). Read `AGENTS.md` first.

**Goal**
A stranger sees, in one viewport, one sentence about what BioWatch is and the two project badges at a size where the animal is legible: the children are the picture, the parent is the quiet frame. Every figure says where it came from and when. FlamaWatch reads as what it is — a project run by a separate organisation that BioWatch links to, not one it operates.

**Design spec**
Skin is W2's tokens, role classes (`.on-paper` / `.on-plate` / `.on-field`) and type scale (`text-note` 14 → `text-hero` 80), copied into `app/globals.css` at build time, never imported. System type only: **no web font** here (a `sign-*` subset may be copied later only if FormosaWatch ships one). No pills, `uppercase`, `tracking-*` or `rounded-full` (except the badge clip), nothing under 14px. Both directions share this structure; Field journal differs only in the hero block becoming paper under a 2px rule instead of a tinted plate.

*Header* 72px desktop / 56px phone: "BioWatch International" on **one** line at `text-lead` 700 (the 9px line goes); two in-page anchors at `text-body`, 44px hit height; no emblem until one is drawn.

*Hero + doors, one plate Section filling the first viewport.* Keep the headline at `text-display` (`text-title` on phone), `text-wrap: balance`. One lead sentence at `text-lead`, ~28 words (from 44). No hero buttons — the doors are the action — then the two doors, side by side on desktop, stacked on phone.

*Door (`Project.tsx` rebuilt).* Badge **256px desktop / 200px phone** (from 96), capped there because the source PNG is 512px and must stay ≥2× its CSS size; raise when the redraw lands. Badge left, text right; centred above on phone. Name at `text-head` with `lang="zh-TW"` / `lang="es"`; Latin name at `text-body`, no caps or tracking; place at `text-note`; the "watches" line at `text-lead` 700; body ~30 words. Stats as a `<dl>` with `<dt>` **before** `<dd>`: value `text-head` `tabular-nums`, label `text-note`, plus a per-stat note at `text-note` quiet ("live, hourly" / "approximate — site unreachable" / "as of 11 Aug 2026") and one card source line. Primary `Button` "Open FormosaWatch"; FlamaWatch gets a secondary one plus the partner sentence. The name carries the `<a>` and an `::after` overlay makes the block clickable, so the accessible name is the project name and the figures stay selectable.

*How it works, paper Section.* Three steps, each ≤35 words; numerals at `text-head` on a rule, not outlined circles. Step 3 keeps the poaching sentence — the best statement of the location policy on either site — and loses "published back to the global biodiversity record".

*Closing, one plate Section* replacing both "Built to be copied" and the three "Get involved" cards: `text-title` heading, two short paragraphs, two `LinkAction`s — "Use the data" → `${FORMOSAWATCH}/attribution`, "Start one where you are" → the contact mail. *Footer* on the dark surface: one-line lockup, mission line, the two project links with FlamaWatch under a "Partner project" label, the contact address, `text-note` floor.

*States* (no JS, so these are build/revalidate states, all three screenshotted): counts live; child unreachable (both figures approximate, notes say so); `species` absent or 0 (records live, species approximate — today this mixes silently).

**How to verify**
`npm run dev -w @biowatch/site` serves on **port 3200** (`package.json:5`). Live stats: run apps/web on 3000, check `curl -s localhost:3000/api/health` reports `reports` and `species`, then start biowatch with `NEXT_PUBLIC_FORMOSAWATCH_URL=http://localhost:3000`. Unreachable: point it at `http://127.0.0.1:9`. Species-missing: serve a directory holding `api/health` with `{"reports":46334}` via `python3 -m http.server` and point it there. **The page prerenders at build time**, so set the variable before `npm run build -w @biowatch/site`, not only before `npm run start -w @biowatch/site`. Screenshots: `npx playwright screenshot --viewport-size=1440,900 http://localhost:3200 fold.png`, again with `--full-page`, and phone with `--device="iPhone 13" --full-page`. Playwright's missing `Accept-Language` does not matter here (no locale routing); it matters only for step 9, where `apps/web` `/` renders zh-TW and `/en` must be opened explicitly. Never delete `.next` while a dev server runs.

**Risks and traps**
- Privacy boundary: the only runtime link to the child is the hourly `/api/health` fetch, whose route comment reads "Deliberately queries through `asPublic()`" — counts through `reports_public` and `web_anon`. Add no example record, no map, no other read; anything later must come from a public endpoint backed by that view, never exact coordinates of obscured records.
- Deliberate, not to be "fixed": `globals.css:3-9` "Copied rather than imported because this app deploys to a different domain and must not depend on the other's build"; `page.tsx:9-16` "Deliberately not a map"; `projects.ts:19-26`, null rather than throwing because "a parent site that 500s because a child is briefly down would be a worse failure than a missing number".
- `projects.ts:12-14`: FlamaWatch's address is unconfirmed and the default is a `biowatchintl.org` subdomain that itself implies shared operation. Do not invent a URL.
- Bigger badges make the stale lettering legible — that is decision 2, and the reason for the 256px cap on a 512px source.
- Shared files: `.github/workflows/ci.yml` (W13 also edits it); `apps/web/messages/*.json` and `SiteFooter` (W3, plus key-parity CI) for step 9 only; W2's token file, copied not imported.
- The domain does not resolve and `verify-deploy` has misfired before: wire no production health check into this work.
