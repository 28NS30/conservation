# W11 — Moderation console

Repo `/Users/neo/conservation`; paths relative to `apps/web`; code read at c73bb8d. Read `apps/web/AGENTS.md` first — this is Next 16; check `node_modules/next/dist/docs/` before writing route code.

**Goal**
A moderator opens `/admin` on a phone or a laptop, in zh-TW or English, and decides a held report without leaving the screen: the photo is legible, the reason it is held is a sentence rather than an English fragment from a library, the species can be corrected, publish and return are one tap each, and a mistake can be undone. No decision the console offers can put an unnamed animal on the public map at its exact coordinate. Visitors never see this page — but every "a person will look at this" sentence W0a gives a reporter is only true if this queue is workable.

**Why / evidence** (claim ids from `../verified-claims.json`)
- `moderation-ux`: `components/admin/ModerationRow.tsx:87-99` renders each photo `h-24 w-24 object-cover` — 96px, centre-cropped — of a 2048px WebP (`lib/image.ts:44-57`) whose full-size URL is signed and downloaded, for up to 100 rows (`admin/page.tsx:78,80-89`). The public record page shows the same photo `w-full` (`reports/[id]/page.tsx:138-149`): the public sees the evidence larger than the person deciding on it.
- `moderation-ux`: `ModerationRow.tsx:115-118` takes the rejection reason with `window.prompt` — the only `prompt(`/`confirm(` in the app; Cancel or empty text silently does nothing.
- `setReportTaxon` (`admin/actions.ts:52-62`) is exported and wired to no control. Correcting the species is the only thing that releases a report held for identification.
- Flag reasons print raw (`ModerationRow.tsx:61-65`): seven English prose strings from `lib/abuse.ts:78-88` and `app/api/jobs/classify/route.ts:216-241,267`.
- Same pattern as `raw-errors`: `ModerationRow.tsx:44` renders `(e as Error).message`, so an expired session shows the literal `forbidden` (`admin/actions.ts:18`).
- `tiny-text`: 10–12px throughout (`ModerationRow.tsx:30,50,62,75,101,108,119`; `admin/page.tsx:93,98`), and `amber-400/700`, `rose-700`, `ember-500` (`:62,101,108`) are Tailwind defaults, not `@theme` tokens, so they survive any palette change.
- `admin/page.tsx:55-61` shows any signed-in non-moderator an untranslated `update profiles set role='admin'…` snippet with their own uuid; `ModerationRow.tsx:75-85` sends the exact coordinate of an unreviewed — therefore possibly protected — record to Google in a URL.
- **Publish can leak an exact coordinate.** `app/api/reports/route.ts:105-109` sets `precisionOverride` only when `awaitingId`, which requires a photo. A no-photo, unnamed report is `pending` with no override, and `publishReport` (`admin/actions.ts:26-35`) only sets `status`, so 發布 publishes an unidentified animal at five decimal places.
- No `robots:{index:false}` metadata (contrast `me/page.tsx:20`); only `robots.ts:12`. `moderation_actions` (`supabase/migrations/0003_reporting.sql:116-124`) is written by every action and read by nothing: no history, no undo, and an acted row collapses to `已發布 · 1a2b3c4d` (`ModerationRow.tsx:28-35`).

**Design spec**
Skin entirely through W2 tokens and primitives; no bespoke colour. The directions differ structurally in one place: under Roundel the phone has a fixed tab bar, so the decision bar sits above it (bar height plus `env(safe-area-inset-bottom)`); under Field journal it sits on the safe area.

*Composition, desktop 1440.* One left-aligned column at `--container-prose`. `Section` heading 審核佇列 at `text-title`; one `text-body` sentence with the count. A `Filter` row of underlined words 待審 (n) · 已決定, the second not rendered when empty. Then decision blocks separated by 1px `--rule` — no borders, no cards (W2 rule 3). Phone 390: same order, 16px gutters, decision bar sticky.

*A decision block*, evidence first because that is what the decision is about:
1. **Photos** at full column width, `object-contain`, capped at 60vh, each opening a `<dialog>` lightbox at `max-h-[80vh] max-w-[90vw]`. List thumbnails request `width: 800` through the new `signedPhotoUrl` option, with the untransformed URL behind the lightbox; if the Supabase plan has no transforms, fall back to the full URL and keep the cap.
2. **The animal**: species name at `text-head`, italic binomial beneath; when there is none, a `StatusTag` 沒有物種名稱 — no empty slot (W2 rule 7).
3. **Why it is held**: a `Notice` carrying a translated sentence from `lib/moderation/reasons.ts`, keyed on the exact strings stored today — 位置在台灣以外。/ 沒有照片。/ 補充說明裡有連結或帳號。/ 模型和通報者說的物種不一樣。/ 模型不確定這是什麼。(both low-confidence strings) / 沒有辨識結果。 A null reason means it is queued for identification → 還沒有人辨識物種。 An unrecognised string falls back to 需要人工檢查。with the raw text in a `<details>`. English to match. **Needs native read.**
4. **Facts** as a `DataRow` stack: when (date only when the stored time is UTC midnight, the same rule W8 uses), category, the note quoted verbatim, the coordinate at 5 dp with a copy action, and a `StatusTag` saying whether the location is blurred or exact.
5. **Decision bar**: primary 發布, secondary 退回, tertiary 更正物種.

*Return flow.* 退回 opens inline in the block — no prompt, no modal: `Choice` rows 不是野生動物 / 看不出來是什麼 / 重複通報 / 其他, a `Field` textarea 退回原因, then 確認退回 / 取消. Confirm is disabled with the reason printed beside it until the text is non-empty (W2 disabled rule), never a silent no-op.

*Species correction.* 更正物種 mounts the existing `components/report/SpeciesPicker` (group derived from `category`) and calls `setReportTaxon`; the block then re-renders with the new name and a `Notice`: 位置的模糊程度已依物種重新計算。/ The blur was recalculated from the species.

*Publish guard.* When `taxon_id` is null and the precision is exact, 發布 is disabled with 先更正物種，或按「發布為未辨識」 beside it; a secondary action publishes with `UNIDENTIFIED_PRECISION` stamped. The server enforces this regardless of the client.

*After a decision* the block collapses to one row: verb, species-or-category, time, 復原 — never a uuid fragment as the only identity.

*Other states.* Signed out: one sentence and a link to `/login`. Signed-in non-moderator: one sentence; the SQL hint renders only when `NODE_ENV !== "production"`. Empty: `EmptyState` keeping today's 目前沒有待審核的通報。— it describes a queue, not whether anybody has reported, so it is not the banned sentence. Action failure: a translated sentence from a small code map, raw text to `console.error` only. Loading: `Skeleton`.

**Risks and traps**
- **Privacy boundary.** This is the one page that reads `reports` (true coordinates) rather than `reports_public`. That is deliberate, and it is why every action re-checks the role: *"A server action is a public HTTP endpoint — rendering the admin page behind a check does not protect the actions it links to"* (`admin/actions.ts:7-13`). Put the role check first in any new action, keep `signedPhotoUrl` server-side, and never import an admin component into a public route.
- **Looks wrong, is deliberate.** *"each action writes its own moderation_actions row *inside* its transaction. A shared helper would run on a different connection and lose that atomicity, so the small duplication is deliberate"* (`:22-24`) — do not refactor it away. *"The obscuring trigger fires on `taxon_id`, so this automatically re-derives the location precision"* (`:47-51`) — never set precision by hand; set the taxon. *"Moderators are deliberately unconstrained"* (`reports/[id]/actions.ts:29-31`).
- **Shared files.** `messages/*.json` is edited by nearly every workstream: add `admin.*` keys only, never reformat, rebase before merge (`admin` is already in `NAMESPACES`, `e2e/pages.spec.mjs:47-70`). `lib/supabase/service.ts` is read by W6 and W8 — make the option optional and default-identical. Do not add a reader of `CATEGORIES[*].color` (`page.tsx:108`); W2's closing PR retires it.
- A Tailwind class with no `--color-*` token emits no CSS silently, so the `amber`/`rose`/`ember-500` classes must all go, not most of them.
