# W13 — QA harness: visual baselines, accessibility, performance, test migration

Paths relative to `apps/web`, read at c73bb8d. Claim ids: `../verified-claims.json`. Infrastructure: no visitor-facing pixel or string changes.

**Goal**
A visitor sees nothing change. Everyone else gets one route table driving screenshots, axe, contrast and render checks; a review gallery of every page × zh-TW/en × 390/768/1440 that a reviewer pages through instead of clicking the site; and CI that fails on a new axe violation, a new contrast failure, sideways scroll at 320, a lost focus ring, or a `/map` load-path regression. `e2e/pages.spec.mjs` then asserts what a page must *do*, not which classes it wears, so W4–W12 can rebuild pages without fighting the suite.

**Why / evidence**
- No visual regression exists. `_shots.mjs` is tracked but its output directory is gitignored (`.gitignore:32` ignores `apps/web/e2e/shots/`), and it covers 9 routes at 1180/390 in zh only (`:27-37`), sleeps 15 s per map page (`:26`), compares nothing. `e2e/map-render.png` is committed (230 KB) and overwritten every run (`map.spec.mjs:100-101`).
- `map.spec.mjs` cannot fail: it prints JSON and never calls `process.exit(1)` (`:106-121`). CI's "Map renders end to end" (`ci.yml:108-112`) proves only that Chromium launched.
- Only home is tested under 1000px — `pages.spec.mjs:180` 1000×800, `focus.spec.mjs:72` 1100×850, `map.spec.mjs:20` 1280×800. `map-mobile-nav` (`SiteHeader.tsx:97-99,130`) lives in that blind spot.
- No axe pass: accessible names are checked on `/map` only (`pages.spec.mjs:273-287`), and `/login` is in neither `PAGES` (`:24-45`) nor `focus.spec.mjs:16-24`, so `login-a11y` and `chart-a11y` pass CI.
- Contrast never runs in CI (`ci.yml:82-113`). `_contrast.mjs` found 4.05:1 parchment-500 and a 1.06:1 chip (`:6-9`, `:123-130`), yet `dark-tokens-on-light` shipped; it hard-codes the page floor `[250,247,240]` (`:110`) and map ground `[11,20,16]` (`:99`), so a new palette skews it silently.
- Nothing measures the load path the owner cares about: no first-tile time, no guard on the `preloadModule` hints (`MapHints.tsx:23-24`, whose comment records "the first tile arrived about half a second sooner on a phone over 4G"), no bundle budget. `tiny-text` is invisible to every check (`design-tokens.test.mjs:20` inspects six hard-coded families).
- Pins that break on the first new composition: badge widths and `main section img` (`pages.spec.mjs:90-102`), three `?category=` doors (`:103,150`), the one-line Latin name (`:105,153`), `[lang="zh-TW"] > span` (`:132`); copy and counts in `home.test.mjs:30,37,51,58,69`; `bg-ink-900 text-paper-50` and `<h3>牠還活著嗎？</h3>` in `report-form.test.mjs:22-33`. `NAMESPACES` (`:48-71`) lacks `team`, so a leaked `team.*` key passes.

**Behaviour spec**
*One route table.* `e2e/routes.mjs` exports `{ path, name, locales, widths, settle, states?, skipShots?, skipAxe? }` for all sixteen `page.tsx` routes plus 404 and the loading states — including `/login`, `/season`, `/team`, `/reports/[id]` and every `/en` twin, which `PAGES` lacks. `/admin` and signed-in `/me` are excluded from shots and gallery: they show exact coordinates. `NAMESPACES` derives from `messages/en.json`'s top-level keys, so the `team` gap cannot recur. Four consumers import the table.

*Gallery.* `npm run shots` writes `<name>[-en][-w<width>]-{fold,full}.png` plus an `index.html` laying zh beside en, 390/768/1440 in a row, with a `?before=<dir>` switch. Map routes get `fold` only — `_shots.mjs:55` says why ("a full-page shot of it is a lie"). States (filters open, points, receipt, empty list) come from a `states` array of driver functions each page workstream contributes. Pixel diffing (`pixelmatch` + `pngjs`, canvas masked) is an opt-in local mode serving W2's "unmigrated pages must not change" claim — never a CI gate; fonts and live tiles make it flap.

*axe.* `e2e/a11y.spec.mjs` injects `axe-core` by `page.addScriptTag`, runs tags `wcag2a wcag2aa wcag21a wcag21aa wcag22aa` at 390 and 1440 in both locales, ratchets against `e2e/a11y-known.json`. **`color-contrast` is disabled**: axe cannot see a WebGL canvas behind chrome and would report exactly the phantom failures `_contrast.mjs:79-92` was rewritten to stop producing.

*Contrast.* `_contrast.mjs` becomes `e2e/contrast.spec.mjs` with `TEST_BASE_URL`, an exit code, both locales, both widths, every route. Its two hard-coded colours are read from the DOM instead: the floor from `getComputedStyle(document.body).backgroundColor`, the dark ground from the marked ancestor's `--ground` (accept `[data-on-dark]`, `.on-dark` and W2's `.on-field`).

*Reflow.* W0d's `checkWidths()` generalised to every route at 320 and 390 in both locales, extended to name the widest element, not merely report that the document scrolls.

*Performance.* `e2e/perf.spec.mjs` hard-asserts: `/map` and `/en/map` carry both MapLibre `modulepreload` hints and the OpenFreeMap `preconnect` + style `preload`; zero font requests on `/map`; every `/api/tiles/` response is `content-encoding: gzip`; JS transferred on `/map`, `/` and `/species` within `e2e/perf-budget.json`; CLS below 0.05 on home and species detail via `PerformanceObserver`. Soft: median first-tile time over three loads, always printed. `map.spec.mjs` gains `process.exit(1)` on a missing `window.__map`, a missing layer, a console error, zero rendered features in the active mode, or no 200 tile response; `map-render.png` leaves git and becomes artifact-only.

*Migration policy* (`docs/qa-harness.md`, where W4–W12 are pointed). **Keep as invariants:** renders in both locales; no leaked i18n key, `pageerror`, console error or 5xx; the three data layers exist; the list skip-link precedes the canvas; every control has an accessible name; panning writes lng/lat/z by `replaceState` without growing history; the Chinese name is `lang="zh-TW"` inside an English h1; no sideways scroll. **Rewrite as intent:** emblem ≥70% of viewport width on phone and ≥320px at 1440, found by hook not `main section img`; exactly one report action and one map action above the fold from 360px up, and home emits no `?category=` link; the name never breaks mid-word. **Loosen, keeping the decision:** `home.test.mjs` keeps "every linked taxon is non-sensitive, non-protected, zh-named" and "every place link opens on a view with public records", derived from the emitted HTML rather than a mirrored `MAP_PLACES` array and counts of 3 and 4; `report-form.test.mjs` reads `aria-checked`/`aria-pressed`; `coverage.test.mjs`, `species.test.mjs` and `map-bins.test.mjs:58` assert the catalogue key and hook, not the literal sentence, chip text or array order. **Delete:** badge-width numbers, the `imageSizes` pin, door counts. `verify-deploy.mjs:67-71`'s wordmark regex becomes a `<meta name="build">` from `NEXT_PUBLIC_BUILD_SHA` (`VERCEL_GIT_COMMIT_SHA` on Vercel); the `<title>` check at `:59` stays.

**Acceptance criteria**
- `npm run shots` produces ≥96 PNGs (16 routes × 2 locales × 3 widths, fold+full where applicable) and an `index.html` that opens with no server; re-running on the same build changes no filename.
- `node e2e/a11y.spec.mjs` exits 0 clean, 1 when `/login`'s `<label>` is removed; `a11y-known.json` reaches empty once W0d merges.
- `node e2e/contrast.spec.mjs` exits non-zero on a deliberately inserted `text-parchment-400` on paper and reports nothing new on `/map` chrome.
- `pages.spec.mjs` passes at 320 and 390 for every route in both locales; hiding `/species` from the phone `/map` header fails it, as does an untranslated `team.*` key.
- `node e2e/perf.spec.mjs` fails when either `preloadModule` line is deleted from `MapHints.tsx`, when a font reaches the `/map` layout, or when `/map` JS exceeds budget; the first-tile median prints every run.
- `map.spec.mjs` exits 1 on a broken paint expression; `apps/web/e2e/map-render.png` is untracked. `focus.spec.mjs` covers `/login`, `/season`, `/reports/[id]`, species detail and the `/en` twins at 390 as well as 1100. CI green under 15 minutes.

**How to verify**
Bring the DB up as `ci.yml:44-56` does. `NEXT_PUBLIC_E2E=1 npm run build`, `npm run start --workspace @conservation/web`, then `npm test`, `npm run test:pages`, `npm run test:focus -w @conservation/web`, `npm run test:map`, `node apps/web/e2e/{a11y,contrast,perf}.spec.mjs`, `npm run shots`. Playwright sends no `Accept-Language`, so every context sets `locale` explicitly (`pages.spec.mjs:179-182`) and each `/en/...` path is its own row — never assume an unprefixed path is English. Capture map shots with headless Playwright only: a hidden browser pane suspends `requestAnimationFrame` and photographs a blank canvas that looks exactly like a bug. The owner's sign-off gallery runs against the Vercel preview URL (`TEST_BASE_URL=https://…`), not CI, whose fixture DB is a thin slice and whose map is not representative. Bogus `JSON.parse` 500s after a `messages/*.json` edit: stop `next dev`, `rm -rf .next`, restart — never while it runs. Mass local timeouts are DB contention; re-run first.

**Risks and traps**
- **Privacy.** `/admin` and signed-in `/me` never enter the matrix, gallery or artifacts — the console shows exact coordinates. Public pages read `reports_public`, so their shots inherit blurring; never "fix" a harness by querying `reports`. Keep `verify-deploy.mjs:174`'s 5-decimal `"lat"` scan.
- **Shared files.** `pages.spec.mjs` is edited by W0b, W0d, W2, W4, W5, W7, W9; `focus.spec.mjs` by W0d and W2. Land PR7 after W0b/W0d merge, keep each helper in a delimited block, warn W4/W5 before moving theirs.
- **Deliberate, do not "fix".** `pages.spec.mjs:196-198` ignores platform-only `/_vercel/` 404s: "Treating that as a page error failed all thirteen renders and read as a site-wide breakage." `focus.spec.mjs:32-45` skips date inputs and says so — "a limitation of the harness rather than a pass being handed out" — so re-check them by eye when W6 restyles. `_contrast.mjs:123-130` measures an element's own text nodes because the subtree version missed a chip "shipping black on near-black, a ratio of 1.06, and this audit reported the page clean". `_shots.mjs:22-26` keeps the 15 s map wait: "Better slow than lying."
- **`data-on-dark`** (`SiteHeader.tsx:56`) is how contrast knows the map is behind chrome; W2 renames it `.on-field`. Accept both for a release, or the audit measures overlay text against the light page.
- **`window.__map` exists only under `NEXT_PUBLIC_E2E=1`**, so shots and perf runs use a build differing from production by one guard; document it. Never assert on a fixed sleep: wait for `window.__map`, its `idle` event and the first tile response — sleeps are for screenshots only.
