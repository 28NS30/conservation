# W9 — Statistics and the seasonal goal

Paths relative to `apps/web` (c73bb8d). Read `AGENTS.md`, `../direction.md` §2.5-2.6, `../inventory/datastories.md`. Screenshots: `shots/stats-*.png`, `shots/season-*.png`.

**Goal**
`/stats` reads as three or four findings a stranger can repeat afterwards ("July is the worst month"; "one toad is nearly three times the next animal"), not a grid of identical beige tiles. `/season` leads with the number that is real and growing — 1,366 squares already hold a record — and shows *which* squares, so the goal can be acted on. Both pages say plainly that every record is imported TaiRON roadkill from 2011–2017, keep zero client JavaScript, and put every chart value in text.

Same in `components/species/MonthlyChart.tsx:22,28,30`. W0d ships the minimum fix (`components/stats/ChartTable.tsx`); W9 carries it, never regresses it.

- The zero hero: `newThisSeason` counts `source='user'` rows (`lib/coverage.ts:77-89`), of which there are none, so the largest type on `/season` is "0 / 40" over an empty track (`shots/season-fold.png`), resetting each quarter.

- Structure: the ember season banner sits above every statistic and is the only coloured block in the fold (`stats/page.tsx:93-108`); `items-start` (`:144`) leaves a ~340px hole (`shots/stats-full.png`); `uppercase tracking-[0.22em]` on Chinese (`season/page.tsx:67`); `max-w-5xl` vs `max-w-3xl` jumps the h1 128px between siblings; the blurring panel's link is labelled 關於本站 (`:288-300`).

**Risks and traps**
- **Privacy.** Every aggregate keeps going through `asPublic()` on `reports_public` (`lib/stats.ts:4-12`). Hotspots and coverage keep `where not is_obscured`: including obscured rows "would pile many reports onto one coordinate and manufacture a hotspot that is an artefact of blurring — and worse, that artefact would point straight at the cell containing a sensitive species" (`lib/stats.ts:200-211`). Build the picture from `coveredCells()` only — never from the tile route, which has no obscured filter — and never draw individual records.
- **Deliberate, keep:** `coverage.ts:65-76` ("An import is a backfill, not an arrival"); `stats/page.tsx:243-252` ("/map, not /: … this link was left pointing at the marketing hero"); `:145-148` (single-category panel hidden); `Bars.tsx:39-40`; `Columns.tsx:41-42`; `season/page.tsx:79-80` (the bar is `aria-hidden` because the number is already in text — and now renders only above zero); `test/coverage.test.mjs:26-33` ("these tests are the only thing standing between the site's one call-to-action number and a silent lie" — change the duplicated SQL whenever the shipped query changes).
- **Standing decisions:** no reward, points or leaderboard (`season/page.tsx:38-40`); never a "nobody has reported yet" sentence — the zero state is designed around, not reworded; TaiRON credited fully without sending readers away; GBIF publication is never stated as a present fact.
- **Shared files:** `messages/*.json` (W0c edits `season.noneYet`, W5 edits `season.seeMap` — append, rebase, never reformat), `lib/stats.ts` (W4), `lib/coverage.ts` (W5 adds `coveredCells`; land after it), `MonthlyChart.tsx` (W7), `e2e/pages.spec.mjs` and `test/a11y-basics.test.mjs` (W0d, W13).
- A Tailwind class with no `--color-*` token emits nothing silently; today's `amber-*`/`rose-*` chips are Tailwind defaults, not project tokens, and must become `StatusTag`.
