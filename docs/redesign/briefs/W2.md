# W2 — Foundation: tokens, type, primitives, guardrails

Paths relative to `apps/web` (c73bb8d). Read `AGENTS.md`, then `../direction.md` §2 (Roundel) or §3 (Field journal), whichever W1 won, for hexes and ratios.

**Goal**
A visitor sees one change: the keyboard focus ring becomes visible on cream. Underneath, every later page shares one token set, a seven-step type scale with a 14px floor, a display face that costs `/map` nothing, and a `components/ui` layer that replaces pills. CI then refuses tiny type, off-palette colour, dead classes and pills, so the old look cannot grow back.

**Why / evidence**
- `tiny-text`: 110 arbitrary `text-[Npx]` in 31 files (59 at 11px; 8px at `components/brand/Wordmark.tsx:49`) plus 200 default size utilities: 19 px values; 16px appears 8 times; ledes are 14px (`components/site/PageHeader.tsx:26`). No check sees it.
- `dark-tokens-on-light`: the global ring is ember-400 (`app/globals.css:130-133`), 2.48:1 on paper. 62 default-hue classes (amber, rose, sky) in 14 files pass CI: `test/design-tokens.test.mjs:20` inspects six hard-coded families.
- Inventory: no primitives; the ember button is typed 13 ways; `rounded-full` (61 uses, 23 files) means action, filter, choice and status alike; no web font (`globals.css:94-97`).

**Design spec**
Three layers; pages and primitives use only 2 and 3.
1. Palette, `app/styles/tokens.css`: `--color-<family>-<step>`. Additive: old tokens and Tailwind's default sizes survive to the closing PR, so unmigrated pages do not change.
2. Roles, `app/styles/roles.css`: `.on-paper` (also `:root`), `.on-plate`, `.on-field` set `--ground --fg --fg-quiet --rule --focus --focus-halo --action --action-fg --action-hover`, exposed through `@theme inline` as `bg-ground`, `text-fg`, `border-rule`, `bg-action`… (the lab calls these `--text`/`--text-quiet`; rename on lifting — `--text-*` is Tailwind's font-size namespace.)
3. Type, `app/styles/type.css`: `text-note` 14, `text-body` 16, `text-lead` 20, `text-head` 28, `text-title` 40, `text-display` 56, `text-hero` 80; line-heights read a variable reset under `:lang(en)`. `font-sign` from `text-head` up, system below. Today's global `palt` stays; only `Prose` switches it off. Structural difference: Field journal's steps are phone/desktop pairs (48/88, 34/56, 24/32) inside the theme, plus a Latin serif. Pages never pick an h1 size; `PageTitle` does.
4. Space, radius, border, motion as §2.4. Containers `--container-page` 1200 and `--container-measure` 680 — not `prose`: the built-in `max-w-prose` (65ch) silently wins.

Primitives (§2.5; heights in the acceptance criteria; no hooks or `"use client"`, so server pages and the client form share them): `Button` (`size="lg"` 56; `<a>` or `<button>`; disabled is `aria-disabled`, reason beside it), `LinkAction`, `Field`, `Choice` (nothing preselected; `mode="radio"` a native radiogroup, `mode="press"` `aria-pressed` buttons that advance a step on tap), `Filter`, `StatusTag`, `DataRow`/`List` (the row is the link), `Section`, `Container`, `PageTitle`, `Prose`, `Figure`, `Legend` (swatch shape equals mark shape), `Notice`, `EmptyState`, `Skeleton`, `Binomial` (`<i lang="la">`). W6's `BigButton`/`ChoiceRow` are `Button size="lg"` and `Choice`; create neither. Field journal changes only `Section` (2px rule, margin heading, no ground) and StatusTag hues; props identical.

Copy (new `ui` namespace, needs native read): `loading` 載入中… (Loading…); `required` 必填 (required); `optional` 選填 (optional); `clearFilters` 清除篩選 (Clear filters); `showData` 顯示資料表 (Show data table); `source` 資料來源 (Source).

**Risks and traps**
- Tailwind silently drops a class with no token: delete none before the closing PR; rename token and classes together.
- `next/font` arguments must be literals — hence the generated file. `cssChunking` merges stylesheets: prove `/map` on a build, not dev. Hand-written `/fonts/…` URLs bypass `basePath` (`lib/basePath.ts`).
- `font-synthesis: none` strips bold from Android system Hanzi. The italic rule hits any `<i>` without `lang="la"`; use `Binomial`.
- Deliberate, keep: doubled MapLibre selectors ("maplibre-gl.css is imported from the component and lands after this file"); the ink ramp ("deliberately stops at 500"); `input:focus` beside `:focus-visible` ("does not reliably match on arrival"); `Badge.tsx` ("`rounded-full` is doing real work"); `Skeleton.tsx` "WATCH THE BOUNDARY".
- Privacy: primitives take props, never import `lib/db`; `/ui-kit` queries nothing; the committed names charset is built through `asPublic` (`lib/db.ts:65`), never from `reports`, so it cannot leak a hidden taxon.
- Shared files: `globals.css` (W0d, W3's `--mark-*` block, W5), `messages/*.json` (append `ui` only), `pages.spec.mjs` (W13, W4), `map/page.tsx` (W0b, W5), `design-debt.json` (per-file keys localise conflicts).
