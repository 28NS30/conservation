# W5 — Map

Repo `/Users/neo/conservation`, site in `apps/web`, read at `c73bb8d`; paths relative to it unless prefixed `packages/`. Companion spec: `../direction.md` §4 "Map" (Roundel) or §3 (Field journal). Read `AGENTS.md`.

**Goal**
`/map` belongs to the site: the island fills the screen, data is readable at every zoom, controls are large and few-worded, and a record opens on the animal's name, not on a missing photo. From the season page a visitor can see which 5 km squares already hold a record. It loads exactly as fast as today.

**Why / evidence**
- Framing wastes the screen: `HeatmapView.tsx:179` pads the right 42% at every width, so at 390px the island gets ~225px and on desktop 55% of the canvas is empty sea (`shots/map-phone-fold.png`, `map-fold.png`).
- Middle zooms look empty: lowest class `#1e3a5f` on black, `dotColor` brightens only at z13.5 (`HeatmapView.tsx:317-328`; `shots/map-x-city-popup.png`).
- Two dark worlds: grey basemap, `#9a9a9a` labels (`lib/basemap.ts:70-72`), rainbow ramp (`packages/shared/src/index.ts:339-352`), stock white popup with inline slate (`HeatmapView.tsx:788-799`), white attribution pill.
- Pills and 10-11px type, the rejected interface language (`tiny-text`): `MapFilters.tsx:129-312`, `MapModeToggle.tsx:42`, `HeatmapView.tsx:1024,1115,1127`, `globals.css:155,171`; 29px zoom buttons.
- The record panel opens on a dashed 沒有照片 box: species at 12px, an 11px link, no source, no mark on the selected dot (`ReportPanel.tsx:94-190`). Two of three type chips return zero-byte tiles and blank the map silently.
- `legend-points` root cause: `CATEGORIES` and `DENSITY_CLASSES` share hexes (`index.ts:15-18,347-352`); W0b fixed the legend text only. `legend-heat`, `legend-type-heat` follow.
- `season-coverage`: `lib/coverage.ts:86-97` returns counts only; `(site)/season/page.tsx:136-141` links to a bare `/map`.
- Small: English-only `map/loading.tsx:14`; ~150 dead lines of hero mode (`HeatmapView.tsx:37-181`); off-token `amber-*` (`ReportPanel.tsx:180`); `getStats` uses `sql`, not `asPublic` (`map/page.tsx:47-56`).

**Design spec**
W2 roles only (`.on-field` on every map surface in Roundel). No pills, blur, translucency, shadows, or text under `text-note`.

*Desktop (≥`lg`).* Band (W3); a row of docked panel, 320px, a flex **sibling** of the canvas (tiles under an opaque overlay are wasted requests), collapsible to a 56px rail; map strip (W3). Panel, top to bottom: 地圖 | 清單 (Filter; 清單 links to `/reports` via `filterToQuery`); species search (Field, 56px rows, the chosen species a row with 移除); years (two native selects); display Filter 圓點 / 方格 / 熱區 (pass `modes`; leave `MODES` alone); colour Filter 密度 / 類型 with W0b's lock; type Filter, groups with records only; checkbox 已有紀錄的 5 公里方格; `MapLegend` at the foot. With any filter on, the first line names it (篩選中：黑眶蟾蜍 · 2015–2017) beside 清除篩選; that line *is* the empty state, never an absence sentence.
Record panel, 400px overlay, right: name at `text-head` system 700; binomial at `text-lead`; the blurred Notice when `isObscured`; category and date in words (`Intl.DateTimeFormat`, `Asia/Taipei`); notes; a source line from `source` linking to `/attribution`; secondary Button 完整紀錄. Photo only when `photo` exists; no habitat chips. Loading is a Skeleton, failure a Notice with 再試一次. Focus moves to the heading; Esc closes and restores it to the canvas. A point that would sit under the panel is brought out with `easeTo` padding (`jumpTo` under reduced motion).
*Below `lg`.* Band, canvas, a 32px in-flow legend strip, W3's strip and tab bar. Top-left a 48px secondary Button 篩選 with a count; top-right 地圖 | 清單; zoom bottom-right. 篩選 opens a non-modal sheet capped at 60dvh; a record uses the same sheet at 45dvh. Sheets end at the canvas edge, so the strips are never covered.
*Framing.* A pure `framePadding(w, h)`: island centred, 16px padding on phone, 8px top and bottom on desktop. If the west edge would fall west of 118.125°E, shift the centre east — at z7 column 105 is empty sea and Fujian yet inside `TILE_SOURCE_BOUNDS`, three wasted function calls.
*Data.* `lib/mapTheme.ts` holds map colours as constants, with a parity test against W2's theme file. Density is `ramp-1…6`; delete `dotColor`. Tune only `SINGLE_REPORT_RADIUS`, shared by dots and points, so dots are ≥6px from z10. Type marks differ by **form**: roadkill and injured solid, invasive solid light, sighting a hollow ring, mixed a quiet neutral. Obscured points (`obscured` is already in the point tile) get a larger hollow quiet ring. Selected: a 3px ring and 2px halo on two filtered layers created at `style.load`, so selecting is a `setFilter`. Data layers sit under the first name-label layer, found via `showsName`, never by id. Cell popup: on-field, `setDOMContent`, count at `text-lead`, cell size at `text-note`, Button 放大這裡; delete the hint pill. `createMap` gains `attribution: false` for `/map`; `MapAttribution` is a `text-note` line bottom-right of the canvas, handed to W3's strip on phone.
*Coverage.* `?layer=coverage`, written with `replaceState`, never in `filterToQuery`. Only when on, the client fetches `/api/coverage` (`[gx, gy]` pairs, ~5 KB gzip, `s-maxage=900`), builds squares from the 3857 lattice, draws a quiet fill under the data.
*Field journal differs structurally:* positron style URL (change `MapHints`' preload in the same commit or the style downloads twice), an inline mask polygon (keep `addMainlandMask`'s geometry), a dark-on-light ramp, panels on paper under a 2px rule, an ink ring with a paper halo, a paper `FALLBACK_STYLE`.

**Risks and traps**
- Privacy: tiles, `/api/reports/[id]`, `namedTaxon` and `coveredCells()` read `reports_public` as `web_anon`. Naming a suppressed taxon "above an empty map would be the only thing on the page confirming it had been recorded here" — the filter line uses `initialSpecies`, never a raw id. "A blurred point that stops saying it is blurred reads as a precise one." `TILE_SOURCE_BOUNDS` "must never shrink". No selected-record id in the URL.
- `CATEGORIES[*].color` is read by the home, stats, me, admin, list and record pages, where the map's light invasive mark would vanish on paper: put map-only marks in `mapTheme.ts` and leave `CATEGORIES` to W2's closing PR. The repaint also reaches `SpeciesMap`, `LocationPicker` and `ReportMap` through `createMap`.
- Deliberate, keep: "The zoom interpolate MUST be outermost" (else "the layer is then silently never added"); "Turbopack's bundled build of maplibre-gl produces a broken Web Worker … the failure is completely silent"; "Sized with h-full rather than `absolute inset-0`"; "No maxBounds. It is not a pan limit so much as a camera override"; "Built by concatenation, NOT `new URL()`"; "Antialiasing is off deliberately"; "history.replaceState directly, NOT router.replace".
- Knowingly reversed, so say so in the PR: "The lowest class is deliberately dark and low-contrast"; "bottom-6 on a phone, not bottom-0" (the in-flow attribution replaces it).
- MapLibre paint cannot read CSS variables — hence constants plus a parity test; a Tailwind colour class with no token emits nothing.
- Shared files: `messages/*.json` (append under `map`, one `season` value), W2's CSS (one delimited block), `map/page.tsx` (land after W3), `pages.spec.mjs` (that block only — tell W13), `packages/shared/src/index.ts`.
