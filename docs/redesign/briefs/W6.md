# W6 — Report flow

Repo `/Users/neo/conservation`; paths relative to `apps/web`; code read at c73bb8d. Read `apps/web/AGENTS.md` first — Next 16, so check `node_modules/next/dist/docs/` before writing route or layout code. Full spec: `../report-flow.md`; read it, this brief scopes it.

**Goal**
Someone standing beside a dead animal on a mountain road answers one question per screen — photo, where, what condition, what animal — and sends in about eight taps with no scrolling, one-handed, with no account. The stored category is derived from those answers instead of asked, the send button is never dead (offline it becomes "save on this phone"), and the receipt says exactly what the server did. `/report?category=` and `?taxonId=` links keep working.

**Why / evidence**
- `form-emphasis` — `ReportForm.tsx:269-322` opens on two rows of 12px pills (通報類型, 牠還活著嗎？); the photo control is a bare 80px `+` with no accessible name (`:369-370`); every `<h2>` is `text-sm font-medium` (`:270,334,405`). The rejected interface language, and the first phone viewport is taxonomy, not the animal (`shots/report-phone-fold.png`).
- Silent defaults on the most consequential field: `ReportForm.tsx:45-47` files `roadkill`/dead unless a pill is noticed.
- `location-default` — `LocationPicker.tsx:74-76` pins Taiwan's centre before anything is chosen; `ReportForm.tsx:458-459` always says 點地圖可調整位置.
- `report-prefill` — `species/[id]/page.tsx:193,262` link to a bare `/report`.
- `tiny-text`, `dark-tokens-on-light` — 11px helpers, a 20px remove button (`:356`), sky-blue EXIF offer on paper (`:425-445`), `text-parchment-400` coordinates (`LocationPicker.tsx:127`), `Turnstile.tsx:55,61` defaulting `theme="dark"` under a stale "the form sits on a dark panel" comment.
- Offline dead end: `ReportForm.tsx:550-555` disables submit without a Turnstile token and Turnstile cannot solve offline, so in production a page opened offline never reaches the queue built for exactly that.
- Privacy gap: `route.ts:109` applies `UNIDENTIFIED_PRECISION` only when `awaitingId`, which needs a photo (shared `:285-290`). A no-photo, unnamed report published later by a moderator sits at exact coordinates.
- Category drift: `confirmSpecies` and `setReportTaxon` never re-derive, so a `sighting` confirmed as invasive stays outside the map's invasive filter.
- `receipt-404`, `status-copy`, `raw-errors`, `injured-guidance`, `receipts-indistinct` are W0a's; W6 inherits its modules and must not regress them.

**Design spec**
Skin through W2: `Section surface="paper|plate"` (form-filling never on field), `Choice`, `Button` (48px; 56px pinned), `Field`, `Notice`; `text-title` H1, `text-lead` rows, `text-note` floor. No pills, no Hanzi under 14px, no letter-spacing on Chinese. Structure is identical under both directions; only ground and face change.

*Frame* — `(flow)/layout.tsx`, URL unchanged. 56px bar: small mark plus 通報 (links home), language switch, ✕ 離開. Five progress segments, **no "2／5" numeral**; ← 上一步 at 44px. The step lives in the hash (`#place`), so browser Back is step Back and the worker still serves `/report` offline (`sw.js:55`, `ignoreSearch: false`); a hash with earlier answers missing lands on the first gap. One `Button` pinned to the bottom safe area, `aria-disabled` and never `disabled`, with a caption above naming what is missing. `QueueBanner` stays mounted in the shell all visit (48px, only when the queue is non-empty) because it owns the queue's Turnstile. The form's Turnstile mounts in the shell on arrival, `theme="light"`, its slot visible only on Send.

*Screens, 390px* — **1 Photo, optional**: H1 先拍一張; a 200px 拍照 (`capture="environment"`), a row 從相簿選 (no `capture`, `multiple`), a text button 沒有照片，直接繼續. Either photo control calls `loadMapLibre()`. The first photo advances with no Next tap. **2 Place, required, nothing defaulted**: H1 在哪裡？; 用我現在的位置 first; 用照片的地點 when EXIF carried GPS (offered, never applied); then the map filling the rest, whole island, **no marker**, overlay 點地圖標出位置. **3 Condition, no default, a tap advances**: 已死亡 / 活著，但受傷 / 活著，沒事. **3b after "hurt"** only: the owner's referral, then 知道了，繼續; repeated on the receipt. **4 Species, a tap advances**: 56px search; 不確定; and 不確定，但應該是外來種 only when alive and well; offline or a search slower than 4s offers 先略過. **5 Send**: the photo large, four 56px rows (place, condition, species, time — the whole row is Change), a closed disclosure 補充說明或信箱（選填）, the privacy sentence. Only Send scrolls. Steps 2-4 carry a 72px thumbnail row. Focus moves to the H1 on each step; steps swap instantly.

*Desktop ≥1024* — same frame, two panes in `max-w-5xl`: left 420px stepper (Enter is Next), right sticky pane holding the drop zone, then a 520px picker map, then the record taking shape.

*Derivation* — `deriveCategory(condition, { taxonIsInvasive, saysIntroduced })`, pure, in `packages/shared`, feeding one `buildPayload()` used by both the POST and `enqueueCurrent()`: dead→`roadkill`; hurt→`injured`; alive and well with an invasive taxon, or "thinks introduced", or arrival by `?category=invasive`→`invasive`; else `sighting`. `taxon_source`: named `user`, not sure `unknown`, skipped null. `CATEGORIES`, `REPORT_GROUPS` and `reportSubmissionSchema` are untouched, so map filters and the queued payload keep working.

*States* — photo: empty, processing, added, unreadable, fifth refused. Place: unset, locating, refused or 15s timeout, coarse fix (kept, shows 誤差約 {m} 公尺), set, outside Taiwan (warn only), map unavailable. Species: idle, searching, slow, no hits, offline, picked, prefilled. Send: checking, needs a tap, ready, ready-with-hold-warning, uploading, sending. No token after 8s adds a secondary 先存在手機裡 while the primary keeps waiting; a submit past 12s adds the same, aborting and enqueuing under the same nonce; `navigator.onLine === false` makes the primary itself 先存在手機裡. Results: published, held (no photo / no species / flagged), queued. Errors come from W0a's code→sentence map, never raw.

*Copy* — every new `flow.*` string in both catalogues; **all zh-TW here needs a native read**. The screen and state text quoted above is the source list; add 同地點再一筆 / Another at this place, 重新開始 / Start over, and the two hold warnings (沒有照片的通報，會先由人看過才公開。 / 沒有物種名稱，要等確認物種後才會公開。). Deleted: `report.subheading`, `type`, `conditionLabel`, `noPhotoWarning`, `identifying`, `speciesUnsureHint`, `exif*`, and the wrong-namespace `t("queueFailed")` (`:203`). The caption above the button only warns; it never promises publication.

**Risks and traps**
- **Privacy.** Public pages read only `reports_public` through `web_anon`; a receipt for a held report exposes nothing to a stranger (W0a's decision). Never suggest writing a species name into `notes` — a public column. Step 2 must not surface an obscured record's exact coordinate.
- **Deliberate, do not "fix".** `flush.ts`: "No token yet is a SKIP, not an attempt"; "A 403 challenge_failed is retryable, unlike every other 4xx." `queue.ts` keeps `VERSION = 1` guarded so "a later VERSION bump does not re-create an existing store". `LocationPicker.tsx:119-124`: "`relative` is load-bearing, not cosmetic." `lib/map.ts`: MapLibre is a raw ES module, never bundled. `sw.js:84-88`: "OpenFreeMap's terms forbid automated collection, so nothing here may ever prefetch." `ReportForm.tsx:376-381`: the file input is `sr-only`, not `hidden`.
- Reset the widget after **any** non-2xx from `/api/reports` — `verifyTurnstile` has spent the token (W0a adds this; keep it).
- `offline-challenge.test.mjs` slices `ReportForm.tsx` between `await enqueue(` and `photos: photos.map`. Keep `enqueueCurrent()` in that file or move the test's `read()` in the same commit; breaking the slice leaves a test that passes while asserting nothing.
- Shared files: `messages/*.json` (W0a, W0c and W4 also edit `report.*` — rebase, never re-add deleted keys), `packages/shared/src/index.ts` (W5 edits `CATEGORIES[*].color` nearby), `e2e/pages.spec.mjs` (W4 owns the doors), `globals.css` (W2 only).
- A Tailwind class with no `--color-*` token emits nothing; `design-tokens.test.mjs` is the guard, and `sky-*`, `amber-*`, `rose-*` must all leave this route.
- Device QA on real iOS Safari and Android Chrome is not optional: a clipped Turnstile may not solve, `capture="environment"` differs, and Android discards the tab while the camera is open — which is what the draft is for.
