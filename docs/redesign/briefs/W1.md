# W1 — Prove the direction: prototypes of two directions on four pages

The spec is two chapters; read both in full first: `../direction.md` and `../report-flow.md`. Today's pages: screenshots under `shots/` (not committed). This brief covers building, hosting and showing. Paths are relative to `apps/web`. Read `node_modules/next/dist/docs` before writing routes: Next 16 differs (`AGENTS.md`).

**Goal**
The owner opens one URL on their own phone, without logging in, and walks home, map, report and species detail in two complete looks: "Roundel" (recommended: forest and cream blocks, heavy Hei, dark map) and "Field journal" (runner-up: paper, Ming serif, rules, light map), in zh-TW and English, on real records, beside today's pages. They pick one direction and one report flow. No live page, URL or test changes.

**Why / evidence**
The owner wants a bigger logo and fewer words, and rejects the data-art island, 你看到了什麼？ and pills; the review says prove a direction on these four layouts first. Each prototype must visibly answer: `header-badge` (`components/brand/Wordmark.tsx:41`); `tiny-text` (`StatusBadges.tsx:141`, `MonthlyChart.tsx:30`, `app/[locale]/page.tsx:200`); the doors (`page.tsx:70-74,221-258`); `form-emphasis` (`ReportForm.tsx:270,334,405`, bare "+" `:369`) and the silent roadkill default (`:45-47`); `location-default` (`LocationPicker.tsx:74-76`); `injured-guidance`; `status-copy`; `legend-heat`, `legend-type-heat`, `legend-points` (`HeatmapView.tsx:601-676, 899-917, 709-721`); `map-mobile-nav` (`SiteHeader.tsx:97-99,130`); island framing (`HeatmapView.tsx:179`, `SpeciesMap.tsx:106-116`); `chart-a11y` (`MonthlyChart.tsx:22`); `report-prefill` (`species/[id]/page.tsx:193,262`); `dark-tokens-on-light` (`globals.css:99-101`). Shown here; fixed live by W0 and W4-W7.

**Design spec**
Hosting (recommended): unlinked, noindexed `/lab/<direction>/…` routes ON MAIN behind `labEnabled() = LAB_ENABLED === "1" || VERCEL_ENV !== "production"`: on in dev, CI and previews, 404 in production until decision 1. Why: previews sit behind Vercel SSO, so the three cold readers and five roadside testers cannot open them and no script can probe them; on production the first tile is timed against `/map` on the same deployment. The site has no users, the lab only adds files, and CI checks every PR. Bounded cost: throwaway code in main (one `git rm -r`), fonts ≤600 KB, shots ≤5 MB committed once. Rejected: a branch per direction (copy and structure drift make the test unfair; two walled URLs).

Routes (each also under `/en`): `/lab` compare page; `/lab/{roundel|journal}` home; `…/map`; `…/report/{stepper|photo-first}`; `…/species/28758` (黑眶蟾蜍, 3,978 records), `/37689` (斯文豪氏頸槽蛇, seven Hanzi, 90 records), `/102062` (nine Hanzi, no records), `/85879` (臺灣穿山甲, protected, no records). All checked on production; the CI fixture holds only the first two.

Identical in both (direction.md §4). Home: emblem 520px desktop / 300px phone, name, tagline, ONE report sign and a map sign; no doors, count or map picture. Map: island fits the width, legend generated from layer, mode and zoom, filter sheet, record panel led by the species name, selected ring, phone tab bar; grid, dots and points with the density/type switch (heat left to W5). Species: the name is the picture, finding sentence, portrait map, chart with values as text, `通報<name>` carrying `taxonId`; a no-record page is hero plus closing block, never an absence sentence. Structural difference: Roundel separates sections with full-bleed paper/plate/field blocks, Field journal with 2px rules, margin headings and one tinted band; each map follows its scheme. Primitives read semantic variables only (`--surface --text --rule --sign --focus --ramp-1…6`) via `bg-(--surface)`-style utilities, named as in §2.5 so W2 can lift them.

Report: both flows share screen 1 and the frame (56px bar, no site chrome, pinned 56px button captioned with what is missing). Stepper: hash steps photo, place (no pin until chosen), condition, injured notice, species, send. Photo-first: the same screen 1, then sections revealed on one page, condition before species, species skippable. STATIC: nothing is POSTed; Send shows the receipt the table gives, forced with `?receipt=published|held|queued`. Real: `preparePhoto`, `useGeolocate`, `/api/species/search`, the picker map.

Copy: reuse live keys (`home.tagline`, `nav.*`); new strings only in `lib/lab/copy.ts`, all "needs native read". A lab bar says 原型，文字未定稿 / Prototype, copy not final.

Shown to the owner: `/lab`. Per page a swipeable trio, Today / Roundel / Field journal (WebP folds at 390 and 1440, both locales), each linking to its live route; the two flows; the "must show" table as a checklist; decisions 2-3 as the questions. Checkpoint A: show both homes when PR3 lands; a direction rejected outright gets no further pages.

- Budgets, on production: no font request on `…/map`; home font preload ≤60 KB (Roundel), ≤190 KB (journal); no `/maplibre/` request on home; CLS <0.05; first `/api/tiles` response on `…/map` within 10% of `/map` (median of 5, 390px, throttled 4G).
- No Hanzi under 14px or letter-spaced; steps 1-4 never scroll at 390×664; `/api/reports` receives no POST.
- `test/lab.test.mjs`: gate, routes (skipping ids the fixture lacks), copy-key parity, the `deriveCategory` table, ramps (step 1 ≥3:1 on land, neighbours ≥1.25).

**How to verify**

**Risks and traps**
- Privacy: read only through `asPublic`/`reports_public` and the public tiles, so blurring is inherited; no coordinates in lists; never write.
- `components/site/Skeleton.tsx:13-18`: under a `loading.tsx`, "Any route beneath it that calls redirect() or notFound() then answers 200 instead". Add no `loading.tsx`.
- `lib/map.ts:9-25`: MapLibre stays raw ESM; bundled, "the worker is constructed and immediately closed, and the failure is completely silent". Carry over `relative h-full`, the `ResizeObserver`, the missing-image resolver, layers at `style.load`, no `maxBounds` before the fit, `FALLBACK_STYLE`, OSM attribution, `withBase()` on hand-written paths.
- `HeatmapView.tsx:52-54`: the mainland mask is "Deliberately NOT applied to /map… Kinmen and Matsu carry real records". The journal's mask must leave both visible.
- `MapHints` is a client component on purpose (server-rendered hints reach every page linking to /map); copy it, preloading positron for journal.
- `test/design-tokens.test.mjs` scans `app/` and `components/` for `<family>-<step>` strings: keep hexes and step names in CSS and `lib/lab`.
- A phone set to English is redirected to `/en/lab`; the lab bar carries the switch.
