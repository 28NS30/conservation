Paths relative to `apps/web`; code read at `c73bb8d`. Context: `../direction.md` §2.5, §2.6, §4.

**Goal**
On every page, including the map on a phone, a visitor sees whose site this is (a legible mark, few words), reaches Map, Species, Statistics, About and Report in one tap, and sees where they are. Switching language keeps path, query and hash. The first Tab stop is a skip link, and chrome stops forcing every page to render per request.

**Risks and traps**
- `pathname.startsWith("/report")` also matches `/reports`: match exactly, or on `href + "/"`.
- Never hand-build `/en` hrefs. `Link locale=` emits `/zh-TW/…`; the proxy 307s it (query kept) and sets the locale cookie.
- No `useSearchParams` in the switcher: nothing wraps the header in Suspense, so the static build would fail.
- An expired auth cookie still shows 我的通報 and `/me` then asks for sign-in. Accepted. Never import `browserSupabase` into chrome.
- Deliberate — keep the intent: "An always-visible 'my reports' that leads to a sign-in wall reads as a gate" (`SiteHeader.tsx:36-38`); "needs no menu button, no JS, and no focus trap" (`:128`); "naming TaiRON and GBIF is a licence condition", and contact stays on the map strip because "a right reachable from everywhere except the busiest page is not reachable from everywhere" (`SiteFooter.tsx:14-15,48-51`).
- `viewportFit: "cover"` changes landscape insets: check MapLibre's corner controls. `map/loading.tsx` must match the new band height or `/map` shifts.
- Privacy: chrome runs no queries; `obscured` stays a prop from pages reading `reports_public`. `Badge` keeps `rounded-full`, W2's one exemption.
- Shared files: `messages/*.json` (only `nav`, `site`, `footer`; parity enforced), `globals.css` (one delimited block), `manifest.ts` (icons only — W10 owns colours, W0c `short_name`), `page.tsx` and `map/page.tsx` (land before W4 and W5 branch), `pages.spec.mjs` (Tab loop only).
