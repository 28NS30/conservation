# W8 — Records list, record detail, My reports, login

Paths relative to `apps/web` (c73bb8d). Read `AGENTS.md` first: this is Next 16. Companion: `../direction.md` §2.5–2.6.

**Goal**
A visitor can browse the 46k published records as a list that leads with the animal and where it was, and open any one on a page whose first line is that animal's name and whose credit names 路殺社（TaiRON）. A signed-in reporter has a home at `/me` where their records' four states are the page, not 11px metadata, and can sign out. Nothing here exposes coordinates or rows the public may not see.

**Why / evidence** (claim ids from `../verified-claims.json`)
- `list-row-target`: only the date links to a record, in body colour (`reports/(list)/page.tsx:263-272`); the species cell goes elsewhere (`:274-287`). W0d fixes the link style and the missing filter line; the row is still a 12px spreadsheet cell (`shots/reports-list-fold.png`).
- Detail hierarchy: `<h1>` is the category at 18px (`reports/[id]/page.tsx:122-130`), the animal an `<h2>` below; no `generateMetadata`, so a shared record carries the site title.
- False time: `:132-136` prints `上午8:00:00` — midnight UTC from a date-only GBIF `eventDate` (`scripts/import-gbif.ts:110-120`).
- `detail-photo-grid`: `:138-150` is 2 columns whatever the count, `alt=""`, no enlargement.
- Credit: `:239-257` is 11px and names GBIF and the rights holder, never 路殺社/TaiRON.
- `ledger-coords` (the convention half): `:209` and `(list)/page.tsx:289` print raw coordinates; no table holds a place name (`0001_init.sql:116-146`). W4 assigns that data job here.
- `tiny-text`: the `/me` journey, the page's point, is an 11px arrow sentence (`me/page.tsx:300-323`).
- Off-token status colour: `amber-700` (`(list)/page.tsx:292`, `[id]/page.tsx:222`), `rose-*` (`me/page.tsx:330`) — outside `FAMILIES` (`test/design-tokens.test.mjs:20`).
- One-way door: `grep signOut app components lib` finds nothing; `/me` never says which address is signed in.
- `receipt-404` residue: `me/page.tsx:211-212` links pending and rejected rows into a 404. W0a makes the link conditional; W8 designs what a held row looks like.

**Decisions needed from the owner** (defaults let work start)
1. **Place names instead of coordinates.** Default yes: `taiwan_admin` from MOI open data, joined on `location_public`. Privacy-neutral — the join runs on the already-blurred point, so a township reveals no more than the coordinate it replaces; above 10 km blur, county only. Blocks PR0 alone.
2. **What leads a record page.** Default: the animal's name; category becomes a status mark.
3. **Credit line.** Default: 紀錄來源：路殺社（TaiRON）經 GBIF 提供，CC BY 4.0, linking to `/attribution` — full credit, reader not sent off-site.
4. **Sign-out plus the signed-in address on `/me`.** Default yes. Not blocking.
5. **Type filters with only roadkill in the data.** Default: render only groups with public records, so no chip is a dead end.
6. **Native zh-TW read** of ~10 new strings. Truly blocking for the copy PRs.

**Design spec**
Skin through W2. Both directions are structurally identical here (Field journal changes rules-vs-surfaces and the hero face only). Reading pages stay on paper with at most one plate block; no cards.

*List, desktop.* `Container` at `--container-page`. `PageTitle` 紀錄; the lede (W0c rewrites `list.subtitle`; the "for screen readers" sentence goes); a `text-note` count 共 {n} 筆; the group `Filter`; W0d's filter line. Still a real `<table>` with `<caption>` and `<th scope="col">`: 物種 (`text-lead` 700 plus `Binomial`) · 類型 (`StatusTag`) · 日期 · 地點 (township, county). 64px rows, 1px rules, and the **whole row is the link** (`<tr class="relative">`, stretched pseudo-element on the species cell). Drop the species-page link from the row: one row, one target. Obscured rows take the ◐ `StatusTag` inline; the ≈ footnote goes.
*Phone (390).* Same table markup, stacked two-line rows per W2's `DataRow` rule: name + binomial, then 類型 · 日期 · 地點 at `text-note`. The markup stays tabular — this page is the map's accessible equivalent and a `<div>` list is not one.
States: loading skeleton matched to the real columns (today's draws 7 chips for 4); `EmptyState` naming the active filters with 清除篩選; paging via W0d's `Pager`.

*Record detail, desktop.* Two `LinkAction`s at the top, 看地圖 and 回紀錄列表, replacing the hardwired 回到地圖 (`:115-120`); no history guessing. Plate hero: zh common name at `text-display` (`text-title` when long), `Binomial` at `text-lead`; unidentified records read 尚未辨識的{category} with the verbatim name beneath. A `StatusTag` row: category, 位置已模糊, protected/endemic. Meta line: date — **date only when `source = 'gbif'`**, date and time only for `source = 'user'` — then township, county. Photos as a `Figure`: one fills the prose measure in an `aspect-[4/3]` box, two or more in a 2-column grid, each opening full size (a `<dialog>` in a small client `PhotoFigure`, or `<a target="_blank" rel="noreferrer">` on the signed URL); alt is `{name} · {category} · {date}`, never `""`. Location: `ReportMap` inside a `Figure` whose heading says what it draws, the blurred-location `Notice` beneath, coordinates demoted into a `<details>` labelled 座標. `SpeciesCard` (W7) under a 2px rule with a `LinkAction` to the species page. `SpeciesConfirm` becomes `Choice` rows, loses the tracked-uppercase heading, takes its errors from W0a's `report.errors.*` with `role="alert"`. One `text-note` source line per decision 3; `source = 'user'` reads 來源：民眾通報. `generateMetadata`: title `{name} · {date}`, description from category and place. Phone: same order, one column, name at `text-title`, map 358×360.

*My reports.* Signed in: `PageTitle` 我的通報, the address at `text-note`, a 登出 `LinkAction`. The stat tiles go; one `text-head` sentence replaces them (needs native read): 你送出 {total} 筆，其中 {published} 筆已經在地圖上，記錄了 {species} 個物種。 / You have sent {total} records; {published} are on the map, covering {species} species. Then a `List` of records, 64px+: name (or 尚未辨識), `text-note` 類型 · 日期, and the journey as four `StatusTag`s at `text-note` 700 with `aria-hidden` separators. Published rows link; pending and rejected rows do not, and carry their state plus the one sentence from W0a's outcome table. 你記錄過的物種 becomes `DataRow`s with counts. Empty is an `EmptyState` with one `Button`.
*Login.* `--container-prose`, one plate block, W0d's `<form>`: 56px `Field`, 56px `Button`, the explain line, `pb-24` so the button never meets the footer rule. Sent state is a `Notice` carrying the address and W0d's resend/change actions.

New copy, all **needs native read**: `list.count`, `list.place`, `detail.coordinates` 座標, `detail.sourceTairon`, `detail.sourceUser`, `detail.unidentifiedOf`, `detail.enlargePhoto`, `me.summary`, `me.signedInAs`, `me.signOut`.

**Risks and traps**
- Privacy: public pages read `reports_public` through `asPublic`; the place join uses `location_public`, never `location`, never the `reports` table. `/me` is the one page reading `reports`, and its WHERE clause is the whole boundary — "There is no id parameter to tamper with" (`me/page.tsx:48-50`); its test greps the source, so moving the guard or renaming `currentUserId` fails CI even when behaviour is fine. Photo paths use the privileged connection only after a public row proved visibility (`[id]/page.tsx:74-75`).
- Deliberate, do not "fix": the obscured circle rather than a pin — "the shape has to be the actual footprint" (`ReportMap.tsx:11-20`), and it "draws exactly what it is handed" (`:48-55`); the photo column that exists only when a photo does (`(list)/page.tsx:140-153`); the plain `<img>` — "a signed Storage URL expires, so next/image's optimiser would cache a URL that stops working" (`:250-252`); `/me` staying private because "a public roster … is a per-person index over taxa" (`me/page.tsx:58-62`); the 12-record floor before a peak month is claimed (`[id]/page.tsx:99-103`).
- Shared files: `messages/*.json` is edited by W0a–d and most later workstreams — add only `list.*`, `detail.*`, `me.*`, `login.*`, never reformat, rebase before merge; a new namespace must join `NAMESPACES` (`e2e/pages.spec.mjs:47-70`) or the leaked-key check misses it; leave `CATEGORIES[*].color` alone (home, stats, admin and the map read it; W2's closing PR retires it).
- With only imported roadkill, place names will look uniform across a few western townships — check a filtered page before calling it an improvement, and keep the coordinate disclosure.
